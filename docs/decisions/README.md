# Nhật ký quyết định

Khi nhóm chốt lựa chọn ảnh hưởng nhiều phần (database, một/nhiều máy, quản lý bàn, quy tắc thanh toán), tạo file `0001-ten-quyet-dinh.md` với:

- Ngày, trạng thái: Đề xuất / Đã chốt / Đã thay thế.
- Vấn đề và ràng buộc.
- Quyết định cùng lý do.
- Tác động, giới hạn và Issue/PR liên quan.

Không coi nội dung đề xuất trong tài liệu là quyết định đã được cả nhóm thông qua.
